# AI Resume ATS Analyzer

## Overview

AI Resume ATS Analyzer is a Flask-based web application that compares a resume with a job description using Natural Language Processing (NLP). It calculates the resume match percentage, estimates an ATS score, identifies missing skills, and provides suggestions to improve the resume.

---

## Features

- Resume Match Percentage
- ATS Score Prediction
- Resume Skill Extraction
- Job Skill Extraction
- Missing Skills Detection
- AI Resume Suggestions
- Responsive Bootstrap Interface
